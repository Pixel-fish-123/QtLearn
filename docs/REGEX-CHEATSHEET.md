# 正则表达式速查表（Regex Cheat Sheet）

> 五大板块：**限定符** / **元字符** / **或运算符** / **字符类** / **贪婪与懒惰**。
> 本文只讲语法骨架，语法细节各引擎基本通用（PCRE / .NET / Python `re` / JavaScript 一致度很高）。

---

## 1. 限定符（Quantifier）—— 控制"出现几次"

限定符永远作用在**它左边紧邻的那一个字符或一个分组**上。

| 写法 | 含义 | 记忆点 |
|---|---|---|
| `a*` | `a` 出现 **0 次或多次** | 可以一次都不出现 |
| `a+` | `a` 出现 **1 次或多次** | 至少要有一个 |
| `a?` | `a` 出现 **0 次或 1 次** | 有它没它都行（"可选"） |
| `a{6}` | `a` 出现 **恰好 6 次** | 精确次数 |
| `a{2,6}` | `a` 出现 **2 到 6 次** | 闭区间 |
| `a{2,}` | `a` 出现 **2 次以上** | 逗号后留空 = 无上限 |

**要点**
- `*` 等价于 `{0,}`，`+` 等价于 `{1,}`，`?` 等价于 `{0,1}`。
- 限定符默认是**贪婪**的：能多匹配就多匹配（见第 5 节）。
- **作用范围只是一位**：`ab*` 是"一个 `a` + 任意个 `b`"，不是"任意个 `ab`"。
  要作用于整体必须加括号：`(ab)*`。
- 想对"一个字符类"整体限次，直接写在类后面即可：`[0-9]{3}` = 连续三位数字。

## 2. 元字符（Meta-characters）—— 有特殊含义的字符

| 写法 | 含义 | 备注 |
|---|---|---|
| `\d` | 匹配**数字**字符 | 等价 `[0-9]`（部分引擎/Unicode 模式下含其他数字） |
| `\D` | 匹配**非数字**字符 | `\d` 的取反 |
| `\w` | 匹配**单词字符**（英文、数字、下划线） | 等价 `[A-Za-z0-9_]` |
| `\W` | 匹配**非单词字符** | `\w` 的取反 |
| `\s` | 匹配**空白符**（含换行符、Tab） | 空格 / `\t` / `\n` / `\r` |
| `\S` | 匹配**非空白字符** | `\s` 的取反 |
| `.` | 匹配**任意字符**（默认**不含换行符**） | 想让它也吃换行需开 `singleline`/`s` 模式 |
| `\bword\b` | `\b` 标注**字符的边界**（全字匹配） | `\b` 匹配位置，不消耗字符 |
| `^` | 匹配**行首** | 多行模式下每一行的行首 |
| `$` | 匹配**行尾** | 多行模式下每一行的行尾 |

**要点**
- 大小写对照就是**取反**关系：`\d`/`\D`、`\w`/`\W`、`\s`/`\S`。
- `\b` 是**零宽断言**：它只判断"这里是不是词的边界"，本身不吃掉任何字符。
  所以 `\bcat\b` 能匹配 `a cat.` 里的 `cat`，但匹配不到 `category` 里的 `cat`。
- `^` / `$` 是**位置锚点**，防"误匹配"最常用的手段：
  `^\d{3}$` 只接受整行恰好三位数字，而 `\d{3}` 会在 `12345` 里匹配出 `123`。
- 要匹配元字符**字面量**（比如真的想匹配一个点号），需要转义：`\.`、`\*`、`\(`。

## 3. 或运算符（OR Operator）—— 在多个候选里选一个

| 写法 | 含义 |
|---|---|
| `(a|b)` | 匹配 `a` **或者** `b` |
| `(ab)|(cd)` | 匹配 `ab` **或者** `cd` |

**要点**
- `|` 的**优先级很低**，作用范围容易超出预期：
  `^ab|cd$` 实际是 `(^ab) | (cd$)`，不是 `^(ab|cd)$`。要限定范围就**加括号**。
- 交替是**从左到右**尝试的（回溯引擎取第一个能成功的分支），所以
  **更具体的分支要写在前面**，否则长串会被短分支"截断"。典型例子见第 6 节。
- 括号同时具备**捕获**作用（分组编号 `\1`、`\2`…）。
  只想分组不想捕获，用非捕获组：`(?:ab|cd)`。

## 4. 字符类（Character Classes）—— "方括号里任选一个"

| 写法 | 含义 |
|---|---|
| `[abc]` | 匹配 `a` **或** `b` **或** `c` |
| `[a-c]` | 同上（区间写法） |
| `[a-fA-F0-9]` | 匹配小写 + 大写英文字母以及数字（即十六进制字符） |
| `[^0-9]` | 匹配**非**数字字符（`^` 在类内表示取反） |

**要点**
- 方括号只管**一个字符**，`[abc]{2}` 才是"连续两个这样的字符"。
- 类内**几乎不用转义**：`[.]` 就是字面点号。但 `]` `\` `^`（非首位）`-`（非区间位置）仍需小心。
- `^` 只有在**紧跟 `[`** 时才是取反；`[a^]` 表示 `a` 或 `^`。
- 类内的元字符大多**失去特殊含义**：`[\d]` 在部分引擎里等价 `\d`，但 `[.]`、`[*]` 一定是字面量。
- 常见坑：`[0-9]` 不是 `[1-9]`；写 IP 校验时前导零问题就出在这里。

## 5. 贪婪 / 懒惰匹配（Greedy / Lazy Match）

| 写法 | 行为 |
|---|---|
| `<.+>` | **默认贪婪匹配**"任意字符"——尽量吃满 |
| `<.+?>` | **懒惰匹配**"任意字符"——够用就停 |

**要点**
- 默认所有限定符都是**贪婪**的。`<.+>` 遇到 `<a><b>` 会一口气吃到最后一个 `>`，
  结果得到整个 `<a><b>`；加一个 `?` 变成惰性后，第一次能闭合就停，得到 `<a>`。
- **在限定符后面加 `?`** 就切换为懒惰：`*?`、`+?`、`??`、`{2,6}?`。
- `?` 的两种角色容易混：
  - **跟在普通字符后** = "可选"（`a?`，出现 0 或 1 次）；
  - **跟在另一个限定符后** = "懒惰"（`.*?`，能少则少）。
- **贪婪并不等于"一定匹配到最长"**：它是"先按最长试，失败了再回退（回溯）"。
  真正要"最长/最短"语义，部分语言提供**独占量词** `*+`、`++`（吃掉就不回退）或原子组 `(?>...)`。

## 6. 实战：把 IP 正则的 `[01]?\d\d?` 讲透

常见的一段 IP 数字正则：

```
25[0-5]|2[0-4]\d|[01]?\d\d?
```

第三段 `[01]?\d\d?` 之所以能一把覆盖 **0–199 的各种长度**，靠的就是**两个 `?`**：

| 部分 | 含义 | 是否必须 |
|---|---|---|
| `[01]?` | 百位只能是 `0` 或 `1`，可有可无 | 可选 |
| `\d` | 至少有 1 位数字 | **必填（地基）** |
| `\d?` | 再补一位，可有可无 | 可选 |

四种组合即 1～3 位通吃：

| `[01]?` | `\d` | `\d?` | 匹配示例 | 覆盖范围 |
|---|---|---|---|---|
| — | 有 | — | `5` | 0–9 |
| — | 有 | 有 | `25`、`99` | 10–99 |
| 有 | 有 | — | `05`、`19` | 00–09、10–19 |
| 有 | 有 | 有 | `007`、`199` | 000–099、100–199 |

三段拼起来正好 `0–255`：`25[0-5]` → 250–255，`2[0-4]\d` → 200–249，`[01]?\d\d?` → 0–199。

**两个必须记住的坑**
1. **顺序不能颠。** `[01]?\d\d?` 里的 `\d` 也能吃下 `2`（即能匹配 `20`–`29` 这种两位前缀），
   所以更具体的 `25[0-5]`、`2[0-4]\d` 必须写在前面。
2. **它会放过前导零**（`007`、`0255` 都能过）。做严格校验时要在两端加边界，例如
   `(?:^|\.)(...)(?:$|\.)`，否则 `256` 可能被拆成 `25` + `6` 而"误通过"。

---

## 7. 一句话总结

| 想要的效果 | 用什么 |
|---|---|
| 控制"出现几次" | 限定符 `* + ? {n,m}` |
| 匹配一类字符 | 元字符 `\d \w \s .`，或字符类 `[abc]`、`[^abc]` |
| 多个候选择一 | `(a\|b)`，注意优先级和分支顺序 |
| 锁定首尾 / 全字 | `^` `$` `\b` |
| 长串被吃太多 | 限定符后加 `?` 转懒惰 |
